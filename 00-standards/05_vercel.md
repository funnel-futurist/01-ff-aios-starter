# Vercel standard

A new Vercel project uses the exact GitHub repository name, including its number, and is linked to that repository. Record its production URL and project name in the README. Verify the Git repository and root directory before renaming a live project; a matching display name alone does not prove the deployed code.

For existing projects, propose a rename map and check production domains first. Deletion requires the owner's approval of the exact project list and one reviewed batch script. A repo marked parked or archived does not by itself authorize deleting its deployment. Never infer that a domainless project is unused without checking its consumers.
