# Folder structure

Number folders a person browses for docs, content, skills, SOPs or curriculum: `01-overview/`, `02-setup/`. Explain each in the README. Keep framework-required names exactly as required: examples include `app/`, `components/`, `lib/`, `public/`, `supabase/`, `.github/` and `.claude/`. Numbering must never break a framework or an installed client instance.

Put only work owned by this repo here. Keep client data inside its authorized client home; never copy one client's data into another's repo or the global AIOS. Keep secrets outside Git. Do not commit screenshots pasted into a chat as a loose asset. An image belongs only when a README or doc actually displays it and explains why.

Retire a folder only after its owner approves an exact move map and links are updated. Archive before deletion. The Starter's existing `00_AIOS/` through `99_Archive/` and underscore naming are grandfathered; its current `taxonomy_rules.md` remains authoritative for installed instances pending a separate release.
