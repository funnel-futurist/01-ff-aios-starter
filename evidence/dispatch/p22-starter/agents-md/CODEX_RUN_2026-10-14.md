# Codex loads the generated AGENTS.md - run record, 2026-10-14

R3-i-2's proof: one real Codex session in a workspace installed by the real installer, answering from `AGENTS.md` without opening a file, and a control without it.

## What was installed
- **Source:** ff-aios-starter `0bbecdea47d1b96bcee0a0a26e2a048cb46e84e4` on `exec/lane01-starter-agents-md-20261014`, the commit that adds the renderer and `AGENTS.md`.
- **How:** `aios release build` at that commit (123 files: 87 managed, 36 seed). A rehearsal-only copy of the record carried the approval string, so the real record was never marked approved. `aios install` ran into a fresh `git init` repository, with identity from a stub `gh`. `aios verify` reported "matches the installed release".
- **The installed `AGENTS.md`:** sha256 `d246a283db1dbec881eb7950d5f7bdb01f3e3daca8f7c539edc97a7941f12e6a`, 15,658 bytes. It is byte-identical to `aios adapters render` output at the source commit.
- **The control:** the same workspace with `AGENTS.md` removed and committed.

## How Codex was run
- **Binary:** Codex CLI `0.162.0-alpha.17.2` (the one inside ChatGPT.app; there is no `codex` on PATH).
- **Model:** the user's configured model, `gpt-5.6-sol`, provider `openai`, reasoning effort set to `low` for the test.
- **Command:** `codex exec --sandbox read-only -c model_reasoning_effort="low" -c 'projects={"<workspace>"={trust_level="trusted"}}' -o <out> "<question>" < /dev/null`, run from the workspace root.
- **Trust:** the project was trusted for the run. Hook trust was not bypassed, so the workspace's own sound hook didn't run. `HOME` pointed at a scratch folder holding `.ai-sounds-paused`, so personal sound hooks stayed quiet too.
- **The question:**
  > Do not open, list or read any files and do not run any commands. Answer only from the project instructions already loaded into this session. (1) What is the exact title (a Markdown heading starting "# AIOS Operator Core") in your loaded instructions? Write it exactly, or NONE. (2) When composing a team message, should you mention bots by default? (3) Where should automated PR health reports go, compared with human project updates? Reply as three lines starting "1:", "2:", "3:". If the loaded instructions do not cover a point, write NOT COVERED.

  Questions 2 and 3 can only be answered from section 1 of Operator Core 1.2.0.

## Not claimed

- **Codex limits:** the default instruction budget is 32 KiB, and a test keeps the file under it. An `AGENTS.override.md` in the same folder appears to replace `AGENTS.md`, so a client who creates one stops getting the core in Codex.
- Skills, safety hooks and the founder-lane guard are still Claude Code only.
