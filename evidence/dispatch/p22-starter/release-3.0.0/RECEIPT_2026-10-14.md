## Not proven here
- **Windows itself.** Case folding was proven on macOS's default disk and a case-sensitive disk image; the planner folds case and Unicode as Windows does.
- **Two Unicode spellings of one name on a real disk:** macOS disks, even case-sensitive ones, store them as one file. The planner's refusal is proven by tests.
- **Vercel projects outside what the client's token can see.** The check refuses when it can't read a scope it knows about.
- **An install killed partway** leaves a partly filled folder to delete and install again. Install isn't journaled. It runs only into a folder that has none of the release's files, and it checks everything else before its first write.
- **A hostile process changing the workspace during the move,** between a check and the hard link. A link can't overwrite, so the worst case is a refusal partway, which `rollback` finishes.
- **The client's own notes that name an old folder.** They're listed, never edited.
