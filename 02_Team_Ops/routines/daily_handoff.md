# Daily Handoff

> VA posts end-of-day summary. Founder reviews next morning. This is the async heartbeat.

---

## How It Works

1. **VA (end of day):** Add a new entry below using the template. Push to GitHub.
2. **Founder (next morning):** Pull latest. Read the handoff. Review anything in `00_AIOS/review_queue/`.
3. **Founder:** Reply inline or add to `feedback_log.md` if changes needed.

**Shortcut:** Open Claude Code and ask: *"What did my VA do today? What needs my attention?"*, Claude reads this file and the review queue automatically.

---

## During an assigned work session

The end-of-day summary is a human review cadence. It does not delay a coordinator's already-authorised next eligible action until tomorrow. Use the existing [assignment and continuation contract](../../.claude/skills/start-my-day/references/reconciliation.md#completion-to-the-next-eligible-action) when a worker returns. Keep execution claims, durable return/turn IDs, verified starts and recovery checkpoints in the unit issue; link that record from this summary. Do not duplicate its queue here. Ordinary workers return only their assigned scope, and sending this summary still requires the applicable authorisation.
